# Replace PrimeVue with Nuxt UI

The app will replace PrimeVue with the latest Nuxt UI during the off-season window, including a Tailwind CSS v4 migration, Nuxt-adjacent tooling upgrades, Zod-based form validation, and a restrained visual refresh with light/dark mode. This is a full replacement rather than a long-term coexistence plan because the app is a solo-maintained personal project, the season break gives room for higher migration risk, and carrying two UI systems would make future work harder to reason about.
