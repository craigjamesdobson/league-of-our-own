# Domain docs

This is a single-context repository.

Before exploring the domain, read:

- `CONTEXT.md` at the repository root, when it exists
- Relevant decisions under `docs/adr/`

`CONTEXT.md` is a glossary of project-specific domain language. Architectural decisions belong in `docs/adr/`. Both are created lazily when the domain-modeling workflow resolves a term or a durable decision.
