## Sprint System

This project uses agile methodology with story point estimation.

### Task Types

- **Feature** - New functionality (e.g., new component, new feature)
- **Enhancement** - Improvements to existing features (e.g., performance, refactoring)
- **Bug** - Something broken that needs fixing
- **Chore** - Maintenance work (e.g., dependencies, tooling, documentation)
- **Documentation** - Documentation updates and improvements

### Task Format

Each task includes:
- **Type** - Feature/Enhancement/Bug/Chore/Documentation
- **Description** - What was done
- **Status** - ✅ Complete, 🔄 In Progress, 📋 Planned
- **Story Points** - Estimated effort (for planning)
- **Date** - When completed or status changed

**Example:**
```
✅ Enhancement: Extract business logic to composables - 3 points - 2025-01-08
🔄 Feature: Advanced player filtering - 5 points
📋 Bug: Fix date parsing in weekly stats - 2 points
```
